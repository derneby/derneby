# Derneby Website

Professional static website for Derneby.

## Files

- `index.html` — main site
- `styles.css` — responsive styling
- `script.js` — small navigation and footer script
- `CNAME` — custom domain placeholder for GitHub Pages

## Publish on GitHub Pages

1. Upload these files to a public GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.

If you own `derneby.io`, keep the `CNAME` file. If not, delete it until the domain is yours.
